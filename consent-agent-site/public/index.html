Data Privacy Consent Agent

Paste business requirements about data collection, consent, and preferences, and receive a structured JSON output.

{
  "processing_activity_name": "",
  "domain": "",
  "data_subject": "",
  "personal_data_collected": [],
  "purpose_of_processing": "",
  "legal_basis": "",
  "consents": [],
  "compliance": {
    "consent_collected": "",
    "notice_provided": ""
  },
  "risk_level": ""
}

Once the site is running, set your OpenAI API key as OPENAI_API_KEY and open http://localhost:3000.
